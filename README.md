# 📝 NotePad — Android приложение для заметок

Современное Android-приложение для создания и управления заметками с использованием Clean Architecture и Jetpack Compose.

---

## 🚀 Стек технологий

* Kotlin
* Jetpack Compose
* MVVM + Clean Architecture
* Hilt (Dependency Injection)
* Room (локальная база данных)
* Coroutines + Flow

---

## 🧠 Архитектура

Проект построен по принципам Clean Architecture:

* **Data layer** — работа с Room и реализация репозитория
* **Domain layer** — бизнес-логика (UseCases)
* **Presentation layer** — UI (Compose) и ViewModel

---

## 🔥 Основные возможности

* Создание, редактирование и удаление заметок
* Реактивное обновление списка через Flow
* Сортировка заметок
* Архитектурное разделение слоёв
